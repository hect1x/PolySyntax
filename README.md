# Vite React App

A simple React app with Vite.

## Project Files

- `index.html` - Entry point
- `src/main.jsx` - React root
- `src/App.jsx` - Main component
- `vite.config.js` - Vite configuration
- `package.json` - Dependencies

## Note

Due to WSL/Node path issues, you'll need to:

1. **Install Node in WSL directly** or use the Windows npm from PowerShell instead of bash
2. **Run from Windows environment** to use the Windows Node installation properly

Alternatively, move this directory to your Windows path (e.g., `C:\Projects\dailySyntax`) and run `npm install` there.

## Quick Fix

From Windows Command Prompt or PowerShell:
```
cd C:\path\to\dailySyntax
npm install
npm run dev
```
